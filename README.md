# Sayed Shadman Sakib — Portfolio

Recruiter-focused portfolio for a Technical Operations Analyst working across fintech operations, production support, automation, data quality, and internal systems.

Stack: Next.js 16 · React 19 · TypeScript · Lucide · Vercel

Local development: npm install, then npm run dev. Open http://localhost:3000.

Routes: / for the portfolio and /resume for the print-friendly web resume.

Core portfolio content is centralized in lib/data.ts and is based on the supplied 2026 resume. The professional portrait in public/profile-standing.webp is an optimized copy of the supplied photo.

The project is ready for GitHub → Vercel deployment on the main branch.

Design direction: dark technical-professional visual system with restrained motion, high-contrast typography, metric-led storytelling, and accessible Lucide icons. UI/UX Pro Max principles are used as design guidance rather than copied templates.
